# Privacy policy — SpacePilot

**Version 1.0 (draft)**

SpacePilot is a local-only tool. It does not send your files or file names anywhere.

- **Processing:** all scanning, analysis and cleaning happens on your device.
- **Telemetry:** off by default. If you opt in, only anonymous usage counts (feature used, duration) are sent; never file paths or file names.
- **Crash reporting:** opt-in. Before sending, the minidump is shown to you and all paths are redacted.
- **Audit log:** stored locally under `%LOCALAPPDATA%\CDClean\audit\`. You can delete it at any time.
- **No accounts, no cloud sync.**
